# Register

## Proceso
1. `register_data_page.dart` : Aqui solicitamos los datos personales, nombre completo, edad, correo y número de telefono
2. `select_verification_page.dart` : Le preguntamos a el usuario el medio para verificarse por correo, SIM o WhatsApp, por momento solo existe el metodo de Gmail
3. `verification_page.dart` : Aquí el usuario ingresara el codigo enviado dependiendo por el metodo selecionado anteriormente
4. `password_page.dart` : Una vez que se verifico correctamente aquí podremos crear nuestra contraseña
