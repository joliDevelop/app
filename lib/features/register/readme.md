# Register

## Proceso
1. `data.dart` : Aqui solicitamos los datos personales, nombre completo, edad, correo y número de telefono
2. `select_verification.dart` : Le preguntamos a el usuario el medio para verificarse por correo, SIM o WhatsApp, por momento solo existe el metodo de Gmail
3. `verification.dart` : Aquí el usuario ingresara el codigo enviado dependiendo por el metodo selecionado anteriormente
4. `pasword.dart` : Una vez que se verifico correctamente aquí podremos crear nuestra contraseña
