# RECOVER PASWORD 

## Proceso
1. Se envia un mensaje al correo proporsionado por el usuario siemple y cuando el correo esté registrado en la BD, esto pasa en `recover.dart`
2. Una vez enviado el mensaje, sera redirigido a `msj_success.dart` donde se le mostrara un mensaje que el mensaje fue enviado correctamente
3. El usuario abrira e mensaje en su correo y vera un botón de **Restablecer contraseña** al precionarlo sera enviado a la web donde hel tendra 15 minutos para poder actualizar su contraseña
